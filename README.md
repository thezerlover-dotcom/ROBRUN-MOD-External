# 🚀 ROBRUN-MOD-External

### Advanced External Modification Suite for Rob Run

**ROBRUN-MOD-External** is an external companion application for Rob Run, featuring an extensive collection of visual overlays, targeting assistance tools, navigation utilities, and customizable gameplay settings.

Designed with flexibility and convenience in mind, it combines multiple tools into one configurable interface with dedicated profiles, hotkeys, and visual customization options.

## 🔍 Detailed Functionality

### 🎯 Target Assistance

A configurable targeting system with individual settings for different weapon categories.

**Available options:**
- Weapon-specific configurations:
  - General
  - Pistols
  - Rifles
  - Shotguns
- Custom activation hotkeys.
- Force-target functionality.
- Target switching.
- Adjustable FOV radius (20–600 px).
- Aim smoothness (1–20).
- Maximum range (25–600 m).
- Configurable movement prediction.
- Adjustable humanization parameters.
- Target filtering by role:
  - Police
  - Robbers
  - Civilians
  - NPCs
- Bone selection:
  - Head
  - Neck
  - Chest
  - Other supported body parts
- Ignore dead, knocked, or vehicle-based targets.

### 👁️ Player Information Overlay

An advanced visual information system providing additional information about players.

**Visual elements:**
- 2D and 3D bounding boxes.
- Skeleton rendering.
- Player nicknames.
- Clan information.
- Weapon indicators.
- Health information.
- Distance display.
- Enemy direction lines.

**Customization:**
- Adjustable colors.
- Box thickness.
- Filled and outlined rendering.
- Distance-based fading.
- Role-based filtering.
- Alive/dead state filtering.
- Hide teammates.
- Hide knocked players.
- Vehicle-related filtering.

### 🤖 NPC Information

Additional visual information for non-player characters.

- NPC names.
- Current state indicators.
- Distance information.
- Configurable visibility.

### 🚗 Vehicle Information

A dedicated vehicle visualization module.

**Information displayed:**
- Vehicle name.
- Owner information.
- Current speed.
- Occupancy status.
- 2D and 3D bounding boxes.
- Custom colors and fill options.

**Additional options:**
- Hide your own vehicle.
- Hide the vehicle you are currently occupying.

### 📷 Camera Monitoring

Visual camera information and monitoring indicators.

- Camera viewing zones.
- Distance information.
- Status indicators.
- Normal, broken, and alarm states.
- Option to hide broken cameras.

### 💎 Loot Overview

A configurable item visualization module with category and rarity filtering.

**Supported categories:**
- Weapons.
- Ammunition.
- Equipment.
- Money.
- Crates.
- Bags.

**Rarity filters:**
- All items.
- Uncommon and above.
- Rare and above.
- Epic and above.
- Legendary.

**Additional features:**
- Loot direction indicators.
- Crate contents preview.
- Configurable item visibility.

### 📡 Radar System

A dedicated radar interface for tracking nearby entities.

**Capabilities:**
- Player tracking.
- Vehicle tracking.
- Adjustable radar position.
- Customizable scale.
- Distance configuration (25–600 m).
- Transparency adjustment.
- Off-screen directional indicators.

### 🏦 Heist Information

Additional information for objects and events related to heist environments.

**Supported objects:**
- Security panels.
- Metal detectors.
- Safes.
- Alarm systems.

**NPC information:**
- Alert status.
- Police notification progress.

### 🔫 Weapon Configuration

Customizable weapon behavior settings.

- Recoil adjustment.
- Spread adjustment.
- Configurable weapon options.

### 🎥 Camera Tools

Additional camera controls for a more flexible viewing experience.

**Freecam**
- Activation key: `F9`
- Movement: `W`, `A`, `S`, `D`
- Vertical movement: `Space` / `Ctrl`
- Speed adjustment: `Shift`
